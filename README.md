# MYSQL-ASSIGNMENT-2---CLAUSES-AND-JOINS

This assignment focuses on using MySQL to retrieve, filter, organize, analyze, and combine data from an employee database.

The assignment is continued from the previous assignment, where the database, tables, and constraints were created. The provided Employee Data DML statements were used to populate the tables before executing the queries.

## Database

The assignment uses an `employee` database containing the following tables:

- `employees`
- `departments`
- `location`

 Topics Covered

The following SQL concepts are demonstrated in this assignment:

- DISTINCT
- Alias using AS
- WHERE clause
- SQL operators
- IS NULL
- UPDATE
- ORDER BY
- LIMIT
- Aggregate Functions
  - SUM
  - MIN
  - MAX
  - AVG
- GROUP BY
- HAVING
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
